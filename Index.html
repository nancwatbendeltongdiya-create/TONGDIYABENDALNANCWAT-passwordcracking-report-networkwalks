1. Introduction

This report documents the successful completion of Week 3 Project Modules focused on Password Recovery / Password Cracking. The objective was to recover the password of a protected PDF file (My Locked PDF1.pdf) using two different methods:

  • Module 1: John the Ripper (JTR) with Johnny GUI
  • Module 2: Networkwalks free online tools (Hash Calculator + Password Cracker)

These labs demonstrate how security professionals test password strength and why weak passwords pose a significant risk.

2. Tools Used

Tool Type Purpose

Networkwalks Hash Calculator Online Extract crackable hash from PDF

3. Module 1 – Password Cracking with John the Ripper (JTR) & Johnny

Steps Performed

  1. Downloaded and installed John the Ripper and Johnny GUI on Windows.
  2. Configured Johnny to point to the john.exe executable.
  3. Extracted the PDF password hash using an online PDF hash extractor.
  4. Saved the full hash (starting with \( pdf \)) into a text file named hash1.txt.
  5. Opened the hash file in Johnny via Open password file.
  6. Started a new attack (dictionary mode).
  7. Johnny successfully cracked the password.
Result: Password successfully cracked → password1
Flag Captured: nw{networkwalks_persistence_jtr_270521}

4. Module 2 – Password Cracking with Networkwalks Free Tools

Steps Performed

  1. Downloaded the encrypted PDF file My Locked PDF1.pdf.
  2. Opened the Networkwalks Hash Calculator.
  3. Uploaded the locked PDF. The tool extracted a crackable hash starting with \( pdf \).
  4. Copied the complete hash value.
  5. Opened the Networkwalks Password Cracker.
  6. Pasted the hash and started a dictionary attack.
  7. The tool successfully matched the correct password.
  8. Used the recovered password to unlock the original PDF file.
Result: Password successfully cracked → password1
Flag Captured: nw{networkwalks_flag_260821_1}

5. Key Observations & Lessons Learned

  • Common and simple passwords (such as password1) can be recovered very quickly using dictionary attacks.
  • Hash extraction is the critical first step before any cracking attempt.
  • Both offline tools (JTR/Johnny) and online tools (Networkwalks) produced the same correct result.
  • This exercise highlights the real-world importance of using strong, unique passwords and enabling multi-factor authentication (MFA).
  • Understanding password cracking techniques is essential for ethical hackers and security testers.

6. Conclusion

Both Project Modules were completed successfully. The password of the protected PDF was recovered using John the Ripper (Johnny) and the Networkwalks Hash Calculator + Password Cracker. The practical experience reinforced the difference between weak and strong passwords and the value of proper security hygiene.
